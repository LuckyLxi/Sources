# 漫画柜

生产插件为根目录 `manhuagui.js`，版本 `1.3.2`。

- 使用用户名或邮箱和密码登录，读取昵称与完整头像地址，校验网站会话后由宿主提交 Cookie；退出时清除插件对应的网站 Cookie。
- 详情信息栏显示作者、题材，以及桌面网页实际提供的地区、读者、出品年代、字母索引、别名；缺失的字段不显示。状态仅显示为标题下徽标，更新至卷／话和评分显示在统计栏。点击题材、地区、读者、年份和字母索引加载对应网站分类，支持分页和搜索排序；作者与别名使用网站搜索。
- 宿主排行榜入口和发现页排行榜均读取网站排行榜，支持分页。
- 云端收藏使用“网站书架”，支持分页、查询收藏状态、加入和移除。每次先校验手机版会话，避免把网站给未登录用户返回的空页面误当成空书架；变更成功后宿主自动刷新云端收藏。
- 章节保留桌面网站的分类和分类顺序，如单话、单行本、番外篇及原作版，组内按阅读顺序排列。
- 评论支持最新、热门排序及分页，登录后可以发表和回复。引用楼层通过 `quotedComments` 保留各自的 ID、作者、正文、赞数和操作，需更新宿主才能显示可交互的楼层。超过三层时默认显示首尾，可展开中间楼层。每层可单独点赞、回复；网站不提供取消赞，已点赞按钮禁用。引用不冒充独立回复分页。
- 相关推荐直接读取桌面版详情页的“看过《…》漫画的用户还喜欢看”列表，保留网站顺序。
- 评分沿用网站的 10 分制加权均分和评分人数。支持新版详情头部和第三版弹窗的宿主可以点击评分，提交 1～5 整星，成功后显示确认提示；投票状态按网站的浏览器规则保存在当前插件中，已投票后只能查看。旧宿主仍能显示均分和人数。

## 验证记录

2026-10-27：通过 `npm --prefix dev run check`、`npm --prefix dev run format:check` 和 `node --test dev/test/manhuagui.test.cjs`。

1.1.1 增加头像字段、相对头像地址和评分成功反馈的回归测试，漫画柜定向测试共 28 项。宿主另行修正详情头部动作对 `SourceTaskCancelled` 的识别：直接关闭评分窗口不显示失败，超时及网站错误仍正常提示；该修复需要更新宿主，不能仅靠更新插件生效。

1.2.0 补上 `categoryComics.ranking` 和 `favorites` 回调，定向测试共 33 项。2026-10-27 联网确认排行榜前两页内容不同，手机版书架的分页路径为 `/user/book/?page=…`，收藏状态与增删协议来自网站公开脚本。已登录书架分页样本为合成数据；真实账号的书架读取、加入及取消收藏仍需实测，未对真实网站修改收藏。

1.3.0 修正章节分类及评论引用展示，增加 `comment_support` 点赞。已抓取《一拳超人》和《鬼灭之刃》的真实桌面章节分组作为固定样本，验证跨分页块的阅读顺序和章节 ID 唯一性。评论楼层、点赞失败回退及单向点赞使用模拟响应测试，未向真实网站点赞或发评论。宿主同步增加可交互引用字段解析与展示。
